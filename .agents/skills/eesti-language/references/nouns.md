# Noun Morphology & Declension (Nimisõna ja käänamine)

Estonian noun inflection operates on 14 cases across singular and plural. There is no grammatical gender.

## 1. The Three Base Forms (Põhivormid)

Every noun has three indispensable base forms from which the rest of the paradigm is formed:

| Form | Estonian | Example 1 (_auto_) | Example 2 (_leib_) | Example 3 (_linn_) | Function |
| --- | --- | --- | --- | --- | --- |
| Base 1 | Nimetav (Nom. Sg.) | _auto_ | _leib_ | _linn_ | Subject, dictionary form |
| Base 2 | Omastav (Gen. Sg.) | _auto_ | _leiva_ | _linna_ | Singular cases 4–14, Nom. Pl., Gen. Pl. stem |
| Base 3 | Osastav (Part. Sg.) | _autot_ | _leiba_ | _linna_ | Direct object, counting with 2+, Part. Pl. base |

---

## 2. Derivation of the Singular Cases

All singular oblique cases (cases 4 through 14) are formed by appending the case ending directly to the **Genitive singular** stem:

```
Genitive Singular: toa (from tuba "room")
├─ Illative:    toa + sse  = toasse (or short illative: tuppa)
├─ Inessive:    toa + s    = toas
├─ Elative:     toa + st   = toast
├─ Allative:    toa + le   = toale
├─ Adessive:    toa + l    = toal
├─ Ablative:    toa + lt   = toalt
├─ Translative: toa + ks   = toaks
├─ Terminative: toa + ni   = toani
├─ Essive:      toa + na   = toana
├─ Abessive:    toa + ta   = toata
└─ Comitative:  toa + ga   = toaga
```

---

## 3. The Short Illative (Lühike sisseütlev)

In addition to the regular _-sse_ ending, many common nouns have a synthetic short illative. In speech and natural writing, the short illative is preferred whenever available.

| Formation Type | Rule | Nominative | Genitive | Short Illative | Regular Illative |
| --- | --- | --- | --- | --- | --- |
| **Vowel lengthening / Q3** | Final vowel remains, syllable is pronounced in overlong (Q3) length | _kool_ | _kooli_ | _kooli_ (Q3) | _koolisse_ |
| **Consonant strengthening** | Strong grade with geminate consonant | _tuba_ | _toa_ | _tuppa_ | _toasse_ |
| **Stem vowel / synthetic form** | Monosyllabic diphthong/long vowel stem | _maa_ | _maa_ | _maha_ / _maasse_ | _maasse_ |
| **-he ending** | Historical _h_-stems take _-he_ | _pähe_ (_pea_) | _pea_ | _pähe_ | _peasse_ |
| **Stem change** | Irregular historical roots | _vesi_ | _vee_ | _vette_ | _veesse_ |
|  |  | _käsi_ | _käe_ | _kätte_ | _käesse_ |
|  |  | _kodu_ | _kodu_ | _koju_ | _kodusse_ |
|  |  | _jõgi_ | _jõe_ | _jõkke_ | _jõesse_ |
|  |  | _linn_ | _linna_ | _linna_ (Q3) | _linnasse_ |

## 4. Plural Formation Mechanics

### Nominative Plural

Always: **Genitive singular stem + _-d_**.

- _tuba_ (Gen: _toa_) -> _toad_
- _leib_ (Gen: _leiva_) -> _leivad_
- _linn_ (Gen: _linna_) -> _linnad_
- _inimene_ (Gen: _inimese_) -> _inimesed_

### Genitive Plural

Formed by adding _-de_ or _-te_:

1. **-de**: Words ending in a vowel in Gen. Sg. with weak or vocalic stems (_majade, autode, kalade, tubade_).
2. **-te**: Words with consonant partitive stems or strong consonant codas:
   - _mets_ (Part: _metsa_) -> _metsade_ or _metste_
   - _mees_ (Part: _meest_) -> _meeste_
   - _laps_ (Part: _last_) -> _laste_
   - _tütar_ (Part: _tütart_) -> _tütarde_
   - _keel_ (Part: _keelt_) -> _keelte_

### Partitive Plural (Mitmuse osastav)

The most morphologically diverse case. Four main patterns:

1. **-sid**: Default for foreign words, words ending in _-e_, or diphthong stems:
   - _auto -> autosid_, _idee -> ideesid_, _ratsu -> ratsusid_.
2. **-id**: Very common after a vocalic genitive stem:
   - _raamat -> raamatuid_, _laul -> laule / laulusid_, _pank -> panku / pankasid_.
3. **Vowel change (-e, -i, -u)**: Synthetic plural partitive:
   - _a -> e_: _kala -> kalu / kalasid_, _tuba -> tube_, _vana -> vanu_.
   - _e -> i_: _leib -> leibu_, _keel -> keeli_.
   - _u / o -> i_: _lind -> linde_, _kool -> koole_.

### Plural Cases 4–14

Regularly formed from the **Genitive Plural stem** + case ending:

- Gen. Pl: _majade_ -> _majades, majadest, majadele, majadel, majadelt, majadeks, majadeni, majadena, majadeta, majadega_.
- Gen. Pl: _meeste_ -> _meestes, meestest, meestele, meestel, meestelt, meesteks, meesteni, meestena, meesteta, meestega_.

## 5. Locative Usages for Settlements & Proper Names

Estonian place names diverge on whether they take internal (_-sse, -s, -st_) or external (_-le, -l, -lt_) cases.

| Settlement / Country | In / At (_Kus?_) | To (_Kuhu?_) | From (_Kust?_) | Rule / Notes |
| --- | --- | --- | --- | --- |
| **Tallinn** | _Tallinnas_ | _Tallinnasse / Tallinna_ | _Tallinnast_ | Internal (most cities) |
| **Tartu** | _Tartus_ | _Tartusse / Tartu_ | _Tartust_ | Internal |
| **Pärnu** | _Pärnus_ | _Pärnusse / Pärnu_ | _Pärnust_ | Internal |
| **Narva** | _Narvas_ | _Narvasse / Narva_ | _Narvast_ | Internal |
| **Viljandi** | _Viljandis_ | _Viljandisse / Viljandi_ | _Viljandist_ | Internal |
| **Haapsalu** | _Haapsalus_ | _Haapsallu_ | _Haapsalust_ | Internal (_-llu_ short illative) |
| **Võru** | _Võrus_ | _Võrru_ | _Võrust_ | Internal (_-rru_ short illative) |
| **Saaremaa** | _Saaremaal_ | _Saaremaale_ | _Saaremaalt_ | External (all _-maa_ names) |
| **Hiiumaa** | _Hiiumaal_ | _Hiiumaale_ | _Hiiumaalt_ | External |
| **Eesti** | _Eestis_ | _Eestisse_ | _Eestist_ | Internal |
| **Soome** | _Soomes_ | _Soomesse_ | _Soomest_ | Internal |
| **Venemaa** | _Venemaal_ | _Venemaale_ | _Venemaalt_ | External (_-maa_) |
| **Ameerika** | _Ameerikas_ | _Ameerikasse_ | _Ameerikast_ | Internal |

### Compound Nouns (Liitsõnad)

In compound nouns, only the final component inflects:

- _sünnipäevakink_ (birthday gift):
  - Genitive: _sünnipäevakingi_
  - Partitive: _sünnipäevakinki_
  - Allative: _sünnipäevakingile_
