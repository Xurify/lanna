# Grade Alternation (Astmevaheldus)

Grade alternation (_astmevaheldus_) is the core morphophonological process of Estonian. It governs the alternation between a **strong grade** (_tugev aste_) and a **weak grade** (_nõrk aste_) in the root syllable of inflected nouns and verbs.

---

## 1. The Two Main Types

### 1. Quantitative Alternation (Kvantitatiivne astmevaheldus)

Only the length (quantity) of consonants or vowels changes, but the sound quality remains the same:

- **pp -> p**: _sepp_ (Q3, smith) : _sepa_ (Q2) : _seppa_ (Q3)
- **tt -> t**: _kott_ (bag) : _koti_ : _kotti_; _võtma_ (to take) : _võtan_
- **kk -> k**: _pakk_ (package) : _paki_ : _pakki_; _hakkama_ : _hakkab_ (Q3 vs Q2)
- **ss -> s**: _poiss_ (boy) : _poisi_ : _poissi_
- **Length reduction (Q3 -> Q2)** without consonant spelling change:
  - _linn_ (Q3, city) : _linna_ (Q2) : _linna_ (Q3)
  - _kool_ (Q3, school) : _kooli_ (Q2) : _kooli_ (Q3)
  - _laulma_ (Q3, to sing) : _laulan_ (Q2)

### 2. Qualitative Alternation (Kvalitatiivne astmevaheldus)

A consonant changes into another consonant or disappears completely (_kaob_):

- **b -> v**: _leib_ : _leiva_ (bread); _tõbi_ : _tõve_ (disease)
- **b -> Ø**: _tuba_ : _toa_ (historical _b_ dropped)
- **d -> j**: _rada_ : _raja_ (path); _sada_ : _saja_ (hundred)
- **d -> Ø**: _riid_ : _riiu_ (quarrel); _vedama_ : _vean_ (to pull)
- **g -> Ø**: _jõgi_ : _jõe_ (river); _nuga_ : _noa_ (knife); _lugu_ : _loo_ (story); _lugema_ : _loen_ (to read); _tegema_ : _teen_ (to do)
- **ht -> h**: _leht_ : _lehe_ (leaf/sheet); _täht_ : _tähe_ (star/letter)
- **sk -> s**: _usk_ : _usu_ (faith/belief); _viskama_ : _viskan_ (to throw)
- **lg -> l**: _jalg_ : _jala_ (foot/leg)
- **lk -> lg**: _palk_ : _palga_ (salary)
- **rk -> rg**: _hark_ : _hargu_ (fork); _mürk_ : _mürgi_ (poison)

---

## 2. Direction of Alternation

Alternation operates in two opposite directions across vocabulary classes:

### Direction A: Weakening Alternation (Nõrgenev astmevaheldus)

The dictionary form (Nominative Sg or _ma_-infinitive) is in the **strong grade**, and the Genitive Sg or Present stem is in the **weak grade**.

| Word Class | Strong Grade | Weak Grade | Strong Grade |
| --- | --- | --- | --- |
| **Nouns** | **Nominative Sg** | **Genitive Sg** | **Partitive Sg** |
| _tuba_ (room) | _tuba_ (strong) | _toa_ (weak) | _tuba_ (strong) |
| _leib_ (bread) | _leib_ (strong) | _leiva_ (weak) | _leiba_ (strong) |
| _sepp_ (smith) | _sepp_ (strong) | _sepa_ (weak) | _seppa_ (strong) |
| _jõgi_ (river) | _jõgi_ (strong) | _jõe_ (weak) | _jõge_ (strong) |
| **Verbs** | **_ma_-infinitive** | **1sg Present (_mina_)** | **3sg Past (_tema_)** |
| _lugema_ (to read) | _lugema_ (strong) | _loen_ (weak) | _luges_ (strong) |
| _teadma_ (to know) | _teadma_ (strong) | _tean_ (weak) | _teadis_ (strong) |
| _õppima_ (to learn) | _õppima_ (strong) | _õpin_ (weak) | _õppis_ (strong) |

### Direction B: Strengthening Alternation (Tugevnev astmevaheldus)

The dictionary form is in the **weak grade**, while the Genitive Sg or Present stem is in the **strong grade**. Common in words ending in a consonant or _-e_.

| Word Class | Weak Grade | Strong Grade | Weak Grade |
| --- | --- | --- | --- |
| **Nouns** | **Nominative Sg** | **Genitive Sg** | **Partitive Sg** |
| _mõte_ (thought) | _mõte_ (weak) | _mõtte_ (strong) | _mõtet_ (weak) |
| _hammas_ (tooth) | _hammas_ (weak) | _hamba_ (strong) | _hammast_ (weak) |
| _kallis_ (expensive/dear) | _kallis_ (weak) | _kalli_ (strong) | _kallist_ (weak) |
| _kallas_ (shore/bank) | _kallas_ (weak) | _kalda_ (strong) | _kallast_ (weak) |
| _tütar_ (daughter) | _tütar_ (weak) | _tütre_ (strong) | _tütart_ (weak) |
| **Verbs** | **_ma_-infinitive** | **3sg Present (_tema_)** | **_da_-infinitive** |
| _katkema_ (to break) | _katkema_ (weak) | _katkeb_ (strong) | _katkeda_ (weak) |
| _pettuma_ (to be disappointed) | _pettuma_ (weak) | _pettub_ (strong) | _pettuda_ (weak) |
| _hõljuma_ (to hover) | _hõljuma_ (weak) | _hõljub_ (strong) | _hõljuda_ (weak) |

## 3. Non-Alternating Words (Astmevahelduseta sõnad)

A large portion of the vocabulary does not undergo grade alternation:

- Words without stop consonants (_k, p, t, b, d, g, s_) in the alternation position: _kala : kala : kala_, _kana : kana : kana_, _elu : elu : elu_.
- Most recent foreign loanwords: _auto : auto : autot_, _arvuti : arvuti : arvutit_, _kohv : kohvi : kohvi_, _buss : bussi : bussi_.
- Derived nouns ending in _-us, -lane, -line, -mine_: _laulmine : laulmise_, _eestlane : eestlase_.

---

## 4. Practical Rule for Learners

When encountering a new noun or verb:

1. Always learn the **three base forms** together (_tuba, toa, tuba_).
2. If form 1 and form 2 have different consonant quantities or vowels, identify whether it is weakening (_pp -> p, g -> Ø_) or strengthening (_t -> tt, mmas -> mba_).
3. The singular cases 4–14 always follow the **Genitive** grade:
   - Weak genitive _toa_ -> _toas, toast, toale, toal_ (all weak).
   - Strong genitive _mõtte_ -> _mõttes, mõttest, mõttele_ (all strong).
