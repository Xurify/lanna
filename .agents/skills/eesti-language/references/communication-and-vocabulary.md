# Practical Communication and Thematic Vocabulary (Suhtlus ja sõnavara)

Token-minimized reference for high-frequency communicative frames and essential vocabulary across CEFR A1–B1 (drawn from the Keeleklikk and Keeletee curricula).

---

## 1. Greetings, Introductions, and Social Formulas

| Situation | Estonian Phrase | English Translation | Grammar / Usage Note |
| --- | --- | --- | --- |
| **Greeting** | *Tere!* | Hello! | Universal neutral greeting |
| | *Tere hommikust!* | Good morning! | Elative *-st* formula |
| | *Tere päevast!* | Good day / afternoon! | Elative *-st* formula |
| | *Tere õhtust!* | Good evening! | Elative *-st* formula |
| | *Tsau! / Tšau!* | Hi! / Bye! | Informal |
| **Inquiring** | *Kuidas läheb?* | How is it going? | Neutral inquiry |
| | *Kuidas käsi käib?* | How are things? | Idiomatic |
| | *Hästi, aitäh!* | Well, thanks! | Standard reply |
| | *Pole viga.* | Not bad / So-so. | *pole* + Partitive |
| **Name** | *Mis su / teie nimi on?* | What is your name? | Informal *su*, formal *teie* |
| | *Minu nimi on...* | My name is... | Genitive *minu* + *nimi* |
| **Origin** | *Kust sa pärit oled?* | Where are you from? | Elative *kust* |
| | *Olen pärit Eestist / Ameerikast.* | I am from Estonia / America. | Elative *-st* |
| **Residence** | *Kus sa elad?* | Where do you live? | Inessive *kus* |
| | *Ma elan Tallinnas / Tartus.* | I live in Tallinn / Tartu. | Inessive *-s* |

| Goal | Estonian Expression | Notes |
| --- | --- | --- |
| **Ordering** | *Üks kohv ja vesi, palun!* | Nominative *üks kohv*, *vesi* |
| | *Sooviksin teed sidruniga ilma suhkruta.* | Conditional *sooviksin*; Comitative *sidruniga*; Abessive *suhkruta* |
| | *Mulle palun päevapraad.* | Allative *mulle* ("to me please") |
| **Preference** | *Mulle meeldib eesti toit.* | *meeldima* + Allative experiencer |
| | *See supp maitseb väga hästi.* | *maitsema* + Allative |

| | *Kas maksate kaardiga või sularahas?* | Comitative *kaardiga* (by card) / Inessive *sularahas* (in cash) |

| Goal | Estonian Expression | Notes |
| --- | --- | --- |
| **Asking Price** | *Kui palju see maksab?* | Standard price query |

| | *Ei aitäh, ma lihtsalt vaatan.* | *lihtsalt* (simply/just) |

## 6. Work and Professions (Töö ja ametid)

To state one's profession, Estonian uses the **Essive case (*-na*)**:
- *Kellena sa töötad?* (What do you work as?)
  - *Töötan tarkvaraarendajana.* (I work as a software developer.)
  - *Ta töötab koolis õpetajana.* (She works as a teacher in a school.)
  - *Minu vend töötab arstina.* (My brother works as a doctor.)

## 7. Celebrations, Calendar, and Wishes (Tähtpäevad ja soovid)

Wishes and festive greetings use the **Translative case (*-ks*)**:
- *Palju õnne sünnipäevaks!* (Happy birthday! — literally "Much happiness for birthday")
- *Head uut aastat!* (Happy New Year! — Partitive)
- *Häid jõule!* (Merry Christmas! — Partitive plural)
- *Head isu!* (Bon appétit! — Partitive)
- *Head teed! / Head reisi!* (Have a safe trip! — Partitive)
- *Õnnitleme teid pulmapäeva puhul!* (Congratulations on your wedding day!)
