# LangHarness

A fork of LearnHarness 0.3.8 for learning Slovak, and any language added from the app,
with bridges from the languages you already know. Built on branch `slovak` from the plan in
`wayfinder-slovak-harness-spec.md`.

## What it adds

| Area | What you get |
|---|---|
| Language profiles | Slovak is built in; every other language is added from the app. Each keeps its own sessions, graph and review deck under `data/profiles/<language>/`. Switch from the language menu at the top of the sidebar or from Settings → Learning, which also removes and adds languages. Switching happens in place, with no restart: the page loads again in the new language, on the same page when that page means the same thing in every language (Review, Listen, Read…), else on Today. Each device keeps its own language: switching on the PC does not change the phone, and a new device starts in the last language chosen. A page already open keeps the language it shows and saves into it, until it is loaded again. Removing a built-in language hides it (`hidden` in `data/profile.json`); **Add a language** brings it back. The running language cannot be removed. |
| Add a language | The language menu's **Add a language…** lists seven languages: Bulgarian, Czech, Estonian, Norwegian, Polish, Romanian and Russian. Pick one and the app builds the whole course in the background (November 2026): about 3,000 common words with glosses and forms from Wiktionary, up to five Tatoeba sentences each, then lessons, chapters, tutor sessions, goals and a story world written by the model you pick (each choice priced first) and checked against the dictionary, or built from the dictionary alone for free. The sidebar's Background section and the Tasks page show each step; a card offers the switch when it is ready. Czech takes about 12 seconds, Russian about 30. Everything is kept in `data/languages/<id>/`. Lessons, the curriculum path, placement, Review, Read, Watch, Speak and the tutor all run on its course. To remove one, press its bin in Settings → Learning: its words go, your progress in it stays. Details: [docs/adding-a-language.md](docs/adding-a-language.md). |
| Seeded grammar graph | A fresh Slovak profile starts with 53 grammar nodes (phonetics, cases, verbs, aspect, word order…) and 40 vocabulary clusters, linked by 57 prerequisite chains. Every grammar node carries an Estonian bridge. Seeding runs once; nodes you delete stay deleted. |
| Prompts | `src/agent/prompts/language/10-<language>.md` joins every agent's prompt. It covers bridges from the learner's own languages (Estonian or Slavic parallels only when the learner lists them, with where each breaks), adaptive immersion, grading diacritic slips apart from grammar, false friends, and the `lookup_word` rule. The languages you know, with their levels and the explanation languages, are kept once for every language in `data/learner.json`; a new language's setup starts from them, and the tutor also hears which other languages you study here and where each stands. Prober, teacher and practice each get a language fragment too. Edit them all in Settings → AI models → Advanced → System prompts. |
| Dictionary-checked forms | `lookup_word` searches the 7,074-word Slovak lexicon exported from slovak.wiki, by form, by unaccented spelling, or by English gloss. The tutor is told to look a word up before it states a form. |
| Audio | Any Slovak in a tutor reply written as `` `say: Dobrý deň` `` gets a play button. Speech tries ElevenLabs, then Microsoft Edge voices, then Piper, then the browser's own voice. Every clip is kept in `data/audio/<lang>/<voice>/<text-slug>-<key>.mp3` and listed in `data/audio/index.jsonl`, so a sentence is paid for once. Speed is 0.75×, 1× or 1.25×; the snail button plays one sentence slower (0.7×, or 0.6× when your speed is 0.75×) and leaves the speed setting alone. Louder voices are turned down to one level, so clips from different voices sound alike. slovak.wiki's clips play as recorded: they are made slowly on purpose, for learners. Volume is a slider in Settings → Sound; in a lesson or Review, hovering or right-clicking the speaker button (or pressing and holding it on a touch screen) drops a vertical slider, and a click still mutes. Settings → Sound → **System voice** lists each of your languages with the voice this device has for it, the last fallback, which works offline. A missing one links to Windows' speech settings when Windows has a voice for that language, and says so when it has none (Estonian). Settings → **Sources** links every outside source the app uses, grouped: words and sentences (Tatoeba, Wiktionary through kaikki.org, FrequencyWords, and for Slovak slovak.wiki, the Slovak National Corpus, UD_Slovak-SNK and the Štúr Institute dictionaries), voices, speech recognition and pronunciation, word lookup, video, the tutor's web search, and fonts, flags and icons. Each has its license where the repo records one, and the section links the research page `/sources`. `src/core/credits.ts` is the list; `tests/credits.test.ts` fails when the server fetches from a host with no credit. |
| Storage | Settings → Data lists what the app keeps on this computer: voice clips, the active language's progress and the reset backups, each with its folder and size. On the desktop app, **Clear cache** empties the app's own copy of audio and pages, which downloads again when needed. Saved clips, progress and backups are never cleared from Settings. The web app cannot clear the browser's cache, so it says where to find it. |
| Letter bar | One click types á ä č ď é í ĺ ľ ň ó ô ŕ š ť ú ý ž into whichever field you used last. Shift types the capital. It folds away. |
| Spaced review | The **Review** page in the sidebar is a Clozemaster-style deck: a real Tatoeba sentence with one word blanked, typed or multiple choice, scheduled with FSRS-5. Missing only accents counts as Hard, not wrong. New words come in frequency order, beginner words first, 10 a day by default. The tutor can add words from a lesson to the deck (`add_to_review`) and see how the deck is going (`review_status`). |

## The redesign (October 2026)

Built after a UX audit of a real 70-minute session, which spent 23 minutes
on placement, 37 minutes waiting at the plan approval and 9 minutes teaching.

| Area | What changed |
|---|---|
| Today (`/`) | The home screen. A greeting; four indicators (days in a row with a flag, today's minutes as a ring against your daily goal, words known, XP); a ridge line showing the whole way to your target level, today's plan with one Start on the next step (each task carries the trail mark of its kind of practice), every other way to practice grouped by kind, and the climb: the stage you are on, chapters as stops on the trail, with the current chapter's units under it, and the Stamps card (the last stamp earned, the three closest). The old graph home moved to `/map`. With more than one language, the plan is every language's own plan for the day, largest share first, each under its flag with its minutes today against its minutes a day; a step in another language switches to it and opens there, and a language not set up yet has its setup as its one step. **Split the day** sets the minutes for the day and each language's share, saved as each language's minutes a day. |
| Chapter exam (`/exam?chapter=<id>`) | Eight choose items drawn from the chapter's own words and drills, with the lesson's options and feedback. The pass mark is 80%. Opened from the last row of an open chapter on the path, which also shows the best score so far. Each attempt is kept per chapter in `progress.json`. Record only: nothing is locked by it yet. |
| Grammar (`/grammar`) | For Estonian, Russian and any other added language: every case the course teaches down the side, singular and plural across, with the case's name in the language and what it does. Each cell opens the lesson that drills that form and shows how often you were right on the first try there; a grey cell says why it has no lesson (the dictionary form, too few sentences) and which tutor session covers it. For Slovak: the six Slovak cases down the side, the three genders across the top. Each cell is the drill that teaches it and shows how often you were right **on the first try, with no help** — the answer before the cue, not the retry it earned; "not yet" until you have tried it (or no drill exists). Point at a cell for its rule and what went wrong: the wrong first tries named as *dictionary form, no ending* / *wrong ending* / *other word* / *no answer*, the accent-only misses counted apart, and the slips you said in Speak. A place name (Bratislava, Košice) drills the cases but has no gender in the dictionary, so it fills no cell. The tutor reads the same measure as its "Measured weak points". |
| Lessons (`/lesson?unit=`) | A full-screen lesson of 12 reps built from the lexicon on the spot, so no rep waits on a model. Reps mix choose (keys 1–4), type, build the sentence, and listen. Each answer gets green, amber or red feedback with the rule and a Why? button that asks the tutor. **I don't know** (always on the footer, outside Blitz) shows the answer at once: it counts as a miss with no XP, and the rep comes back once at the end. Combos, sounds, confetti and XP. Missed words go into the review deck. The end screen shows the share right the first time over one tile per answer (filled right, half-filled accent slip, hollow miss), today's goal, days in a row and the words added to Review; beside it, each missed sentence with its audio, what you answered and how it went when it came back. Its heading and the praise after a right answer are in the language you study (Slovak, Estonian, Russian; English for others), the heading with an English gloss. |
| Aspect and demonstratives (E42) | Reachable now: in the six aspect chapters' Dvojičky steps (everyday, health, shopping, plans, moving, stories), up to three task reps at reps 4, 8 and 12 of the lesson. A **grid** shows one aspect pair's table with its cells empty, tenses down the side and aspects across the top, and asks which cell a given form belongs in: you place the form by its cell label, and the forms and notes appear once you answer (the perfective present is labeled as the future meaning). A **cue** rep shows a verified sentence and asks which word made its form, naming the verb and its twin ("Which word made it robiť and not urobiť?"); six approved rows make one. Tasks are never a first try or a mix-up, and a task seen in the last lesson goes to the back of its chapter's pool. After a miss on an aspect pair, a static explanation opens in the Why? panel (the contrast, a timeline labeled as an example, three cue points, one slovak.wiki link). Not drilled yet: the aspect mix-ups (no aspect pair has approved sentences on both sides) and the demonstratives (no approved rows). The explanations and the approved rows wait for the verifier's sign-off. |
| Blitz (`/lesson?mode=blitz`) | 60 seconds of choose reps across the units you have started, with a best score. |
| Progress | `data/profiles/<language>/progress.json` holds XP, days, unit levels, the streak and the stamps with the day each was earned. One rest day is forgiven after six active days. Each day also keeps its minutes per activity (`minutesBy`), measured while you were active: the gaps between your actions for lessons, Review, Speak and the like, the time the tab is visible and focused for Read and Listen, and for Watch the time its video plays, plus the time a paused line waits for your decision (up to 2 minutes a line), and the questions (up to 90 seconds after your last action), with the tab visible and focused. |
| Review | A single Continue button takes the suggested rating (Enter). The four ratings stay as a quiet override row. Reviews earn XP. A wrong answer says why under the correct one: the word you wrote is a different word (with its meaning, from the dictionary), the dictionary form, or the right word with another ending; then the form the sentence needs and the preposition that decides it ("po decides the case: locative of večera"). After I don't know it names the word and its meaning; after a right answer it shows the word (a link to it in Words), its meaning and its form. Under the answer, a line says where the sentence comes from, slovak.wiki or Tatoeba. A bookmark button saves the sentence to your phrases (Words → Phrases, filter From review). |
| Words search (`/words`) | The search box takes a headword, a form, an English meaning or a few words of an example sentence: `veľký záujem` finds the sentence that has those words side by side, and the last word may be unfinished. `/words?search=záujem` opens the page with the search filled in. Accents are optional. Saved phrases have their own search on the Phrases tab, which matches any part of the phrase or its translation. |
| Setup (`/start`) | The minute that replaced the placement chat (October 2026). Four screens: what Slovak is for (can-do purposes that set the target and the Talk scenes), what you bring (the languages you know with a CEFR level each, how much Slovak), minutes a day and days a week (with the date that pace reaches the target), and the placement check, rebuilt on 2026-10-28 after the fixed staircase proved "clearly wrong" (eight items a tier, pass at six, half of them multiple choice, one dictionary word accepted per blank). Now three stages (`src/core/placement-ladder.ts`, `src/server/placement.ts`): an adaptive ladder over the sixteen drill units — every typed item is chosen from the answers before it (a rung held jumps halfway up the open bracket, a gap halves it down, one each asks a third), it enters where you said you stand and closes the bracket in about a dozen items, and a typed answer the dictionary did not expect goes to the cheap model slot, which accepts a valid alternative ("Zostal sam doma") and, on a miss, reads your earlier answers so its note can name a repeated mistake with the earlier form; then the Socratic stage, where the tutor (strong slot) asks up to six production questions on the units at the edge, judging each held / slip / gap, and its verdicts replace the drill's on those units; it also asks again about the rung your level rests on (the highest one the drill held on two right answers), in a new sentence and then why, because a lucky pair there would credit every rung below it (since 2026-11-05); then a two-minute yes/no word check (forty words across five frequency bands plus eight pseudowords, X_Lex style) that measures vocabulary instead of inferring it from grammar. The result shows the tiers, the tutor's reading of the edge, the words by band, and every miss as evidence. Units you hold are tested out, the chapters behind your edge are skipped (open to revisit), misses come first in the daily plan. A re-check starts from your current chapter and never places you below it. Every item, judgement, turn and tick is kept under `data/profiles/slovak/placement/`, and the check's model calls show in Settings → Spending. The tutor gets all of it as a "This learner" block in its prompt. |
| Chat (New chat, Why?) | A plain conversation with the tutor (November 2026, E76). Ask anything; the reply is two short paragraphs at most, every form with its meaning, a drawing when the idea has a shape (written in the reply, in the app's ink look, sometimes in steps you tap through), and one question at the end. Answer in the same box. The tutor writes in a reading face (Fira Sans); your answers sit in the text with a tick or cross, and a pen stroke shows while the tutor writes (E85). The chat opens the moment you press Enter, and the tutor knows what the app has: ask "do we have lessons on…" and it links the units, scenes and pages, each opening in place (November 2026, E77). Under the reply: Hint, I don't know and Explain it another way when a question is open; Quiz me, Explain it another way and Draw it otherwise. No test before the answer, no plan, no question cards, no model picker: the chat uses the strong slot's model at a low thinking level (the cheap slot's for Why?). A first miss gets a cue, the form comes after a second. `/chat/new?mode=teach` still opens the probed lesson below, `?mode=practice` the drills. |
| Tutor chat (probed lesson) | Agent machinery (file reads, map lookups, reasoning) is hidden behind a Working toggle. Answers are one tap or one number key; confidence and thinking sit behind "Explain my reasoning". Placement is capped at about 5 questions, a question you write in the thinking field gets answered first, and teaching starts without a plan approval. |
| Talk and Story | Talk in writing (Today's Talk tile) is the Speak screen with the keyboard on (`/speak?mode=typed`): the same six scenes, the tutor answers out loud, you type each line and press Enter, and Koniec gets your corrections. Story is Read, the Martin episode with its questions. Neither has a chat any more (`docs/DECISIONS.md`, E8). The daily plan's speaking step is the spoken Speak task below. |
| Speak (`/speak`) | The output strand, said out loud (October 2026). A scene from what Slovak is for (café, the street, a new colleague, the market, the doctor, family; the chapter's own scene and your purposes' scenes come first). The tutor plays the other person on the cheap model slot: every line arrives as audio and text, the meaning a tap away. You hold the mic, say your line, and it is transcribed (ElevenLabs Scribe with the ElevenLabs key, else Deepgram; typing is always there) and sent as it was heard. With an Azure Speech key every spoken line is also scored sound by sound (accuracy, fluency, completeness and, where the locale has it, prosody — stress and rhythm, the nearest honest measure of accent): a chip on the line, +2 XP for each line said clearly, the scene's average at the end. A slip in a **case ending, verb ending or aspect** comes back as a prompt to repair yourself — *(do škol…? skús ešte raz)* — never as a silent recast (prompts change grammar, recasts are not noticed); everything else waits. After about eight lines, or when the scene ends, or on *Koniec*: at most three corrections (yours → the right line, the rule in a few words, played aloud), two phrases to keep, the slips' words into the review deck. Every scene is kept once under `data/profiles/<language>/speak/` with your own recordings line by line. |
| Speed (`/speed`) | The fluency strand (October 2026): nothing new, only faster. **Read it faster** times you re-reading an episode you have already read, shows words a minute against your recent pace on it (the middle of your last three; a level guess the first time), then asks one of its questions. The speed bonus is paid only when the question is right and the pace is a real reading pace (up to 450 words a minute). **Speed** gives six sentences every word of which you know (the ones you got right in lessons first), each heard once and then said three times in a shrinking window (the window shrinks on purpose: the research supports the repetition, and its own authors warn that tight time limits can cost accuracy, so the page says so); with the microphone on, a pass ends when your voice does (the silence after it is not counted) and is scored before the verdict, and a recording with no voice does not count: **a pass counts only if it was inside the window AND clear** (70 or more — sound by sound with an Azure Speech key, else the words speech-to-text could make out), so a fast mumble does not pass. Without a microphone the round is self-timed and says so, next to a Mic off line that names the reason (no speech-to-text key, a browser that cannot record, or a blocked microphone) and opens the key settings. The end screen shows your pace in words a second from the first pass to the last, against the round before; it is repetition on the same lines and says it does not show you are quicker on new ones. Both end screens list the sounds and words that keep scoring low across your recent lines, with a play button on each, and fold a "Why this works" note with the studies behind the page. The plan alternates the two once an episode has been read; Blitz stays. All local, no model. Rounds go to `data/profiles/<language>/fluency/log.jsonl`. |
| Read (`/read`) | A reading task (October 2026): one episode a day of *Martin in Bratislava*, written at your level on the cheap model slot (6–8 sentences at A1 up to 16–20 at C1, about 97 of 100 words you know, 2–3 new words each used three times, a setting drawn from what Slovak is for). Tap any word for its lemma, meaning and tags; the speaker plays a sentence, Play all reads the episode; a translation per sentence on demand. Three meaning-only questions follow, then the new words and whatever you looked up go into the review deck. Every episode is kept once under `data/profiles/<language>/stories/` with its glossed tokens, questions and cost; reading it again is free. The library lists every episode with your score. |
| Listen (`/listen`) | The input task (October 2026, from the comprehensible-input research): ten real dictionary sentences you can follow, each heard first with the text hidden, then typed as the Slovak you heard (dictation, graded like a lesson's listening rep; a sentence with only a missing accent earns half XP). "Didn't catch it" counts the sentence as missed without typing anything. Picking a meaning from three was removed in November 2026. Then shown with its one new word marked and glossed. One new word a sentence at most; the ten together keep at least 93% of their words known (the Read task's own known-words estimate). Typed answers are graded by the server. For the speed measure a sentence is timed by its clip and the plays it took, not by the typing. No grammar grading. New words go into the review deck; the session goes to the lesson log as mode `listen`. Built locally, no model; audio from the cached library. |
| Sound (`/sound?id=`) | The sound step (November 2026, the first slice of phase 7): one vowel-length contrast at a time. A listening check on the two words (choose the one heard), then shadowing: each line plays, you have a short gap, then you say it, and the clarity score says whether it was clear. Three tries per line. Two pairs so far (pas/pás, rad/rád), each line a verified example sentence. Not on the path yet, and nothing is saved. Comparison with the tutorial: [docs/research/shadowing.md](docs/research/shadowing.md). |
| Watch (`/watch`) | Paste a Slovak YouTube link (October 2026: "double subtitles, so I see both as I watch"). The app fetches the video's Slovak captions (YouTube's own, made by people or automatic; yt-dlp when the app cannot reach them; with yt-dlp and a Deepgram key, a video with no captions can be transcribed from its audio on request), cuts them into lines the ear can hold, translates them once on the cheap model slot, glosses every word against the lexicon with the same known-words estimate the Read and Listen tasks use, and writes a comprehension check at your level. Before watching: how much of the video you know (93% is where listening works on its own) and the unknown words worth meeting first, with their sound; tick one you already know and it counts as known from then on, here and everywhere the app measures what you know (the tap-a-word card has the same "I know this", which also undoes it; kept in `data/profiles/<language>/known.json`). With no Slovak captions, the Czech ones are used and the video is labeled Czech (Czech is close to Slovak, but its words are not Slovak). A video spoken in another language you study (a Russian video while Slovak runs) is not prepared in the wrong language: the page says so and offers "Switch to Russian and add it", which runs that language and prepares the video there. The video plays in YouTube's own embedded player, nothing downloaded. Line by line (the default): each line plays with the text hidden and the video pauses; replay (R), slow it down (S), show the Slovak (T), show the meaning (M), then Got it (Enter) or Not yet (N). Straight through: both subtitles live, the transcript below, click a line to jump. Every word tappable. The end screen shows the lines got on the first unaided listen and the words a minute of that speech (the listening-speed signal), the check, and the words now in your deck. Then "Use the words" (a Slovak video only): one sentence for each of up to three words, the ones you tapped first and then the video's own new words. A program checks each sentence first, then the cheap model slot judges it; the meaning shows after your first try, and a word earns 5 XP the first time it is accepted for that video. A video you added waits on Today's plan as a Watch task until watched; watching counts toward the input strand. Everything is kept under `data/profiles/<language>/videos/` (the caption track as fetched, the lines, the questions, every watching with per-line stats). |
| Watch picks (`/watch`) | November 2026: "connect our YouTube account… pick videos or find videos based off that", and save creators. The page is a link field (press `/` to reach it), the one next step when there is one (a video ready to watch, or the best pick you can follow), and four tabs that stay in reach as you scroll. **For you** lists videos from your saved creators and your YouTube as cards, best fit first, those at your level (88% known or more) under their own heading: each shows its length, how much of it you know (the words you have studied, measured on its captions with no AI request, as a bar along the thumbnail and in words) and whether people made the captions. Prepare one, or press × to never see it again. **My videos** is what you have prepared. **Creators**: paste a channel link, an @handle or one of their videos; the app reads their newest uploads from YouTube's feed. Open a creator to search their channel or list their newest videos, best for you or newest first; a video that cannot be offered says why. **YouTube**: in the desktop app, Connect YouTube opens a Google sign-in window of the app's own. The app reads your history, your recommendations and the channels you subscribe to, keeps only those lists (never your password or cookies), and suggests the channels among them that speak the language. The card says who you are signed in as, with your name, @handle and picture (read from YouTube's account menu; your email is never kept). Sign out clears the window's session and who it was; Forget what was read drops the lists. In the browser, or if Google refuses the window, add a Google Takeout export (`watch-history` and `subscriptions.csv`). Every video is checked before it is offered: is it really spoken in the language (many have only translated subtitles), how much speech it has, and how much of it you know. With an AI key, the cheap slot writes six searches in the language from your interests, once, and YouTube's search with subtitles finds more. **Keep one ready** (on, needs an AI key) prepares the best pick you can follow (88% known or more) when no video waits, so Today has a Watch task. The picks are checked again when Watch or Today opens and they are over six hours old. **Pick a stretch**: the scissors on a pick, a creator's video, a video in Your videos, or beside the link field opens a strip of the whole video coloured by how much of each moment you know, with the best stretches for you listed (about two minutes at 93–97% known, new words that come back, speech all the way through; found with no AI request). "Known" is the words you have studied, plus grammar words, names and numbers; beside it each stretch shows what is expected at your point in the course (the same word credit as the Milestones page), which never ranks anything. Videos kept before a change in how this is measured are measured again, locally, when you open Watch. When nothing in a video is within reach of your words, the panel says so and lists the nearest stretches instead of the best. Drag on the strip to pick your own; **Prepare this stretch** translates only those lines, so it is cheaper and any video up to 3 hours can be cut. One cut is kept per video. Videos up to 90 minutes can be prepared whole. **Study sections** (needs an AI key): on a prepared video, Find sections asks the cheap model once for up to three parts worth studying and the words in them, checked against the video's own lines and kept; Practice makes each word a typed gap in its real line, and misses go to Review and back to Listen. Kept in `data/profiles/<language>/videos/discover/`. |
| Get ready (`/watch`) | November 2026, for a video rated hard or too hard ("make pre-content for me to use and learn from… then I finally watch the video"). On a prepared video's preview, under how much of it you know, **Get ready** (needs an AI key) asks the cheap model once for a briefing, checked against the video's own lines: **What it's about** (in English, then the video part by part with the times, as statements), **The short version** (five to eight short sentences in the language at your level, written by the model and glossed from the dictionary, each spoken, every word tappable, the English behind a switch; it says how many of its words you know and how many your level expects, and is written again once when it is too hard), and **Words to listen for** (six to twelve words or short phrases copied from the real lines, each with its meaning and its line, spoken). **Type them** makes each word a typed gap in its real line: the first miss shows the first letter and the line's English, the second the answer; "I don't know" is a miss; XP as a lesson's typed reps, misses to Review and (captions made by people only) their lines back in Listen, and the briefing says when you last typed the words and how it went. Under 88% known the offer leads the preview; above it is a quiet one. Nothing is gated: you can always watch without it. Get ready again asks once more. A video with Czech captions is briefed from the Slovak rendering of them (the one its known share is measured on), and the screen says the speaker says the Czech. Regenerate on the preview now shows its step and opens the new version when it is done. Kept in `data/profiles/<language>/videos/prep/<id>.json` with its cost (Settings → Spending, under Videos). The research and its limits: `docs/research/pre-listening.md` and the Watch sources note. |
| Desirable difficulties | The standing rule (2026-10-28: "things should be hard… that is where the learning happens"), written up in `docs/research/desirable-difficulties.md`. Every rep is retrieval first, help is graded and priced, difficulty rises with mastery. Lessons: the first miss shows only the smallest cue (the trigger word, or which form is wanted); the rule and bridges come with the answer after the second miss, opened by themselves. A missed choice retries typed. From the practiced stage on, the English is hidden until the answer ("Meaning · half XP" shows it early). A complete unit is **strong**: production only, six reps from the units it is confused with, meaning hidden. Review: the hint is graded (meaning, then the word) and caps the rating (Good, then Hard); a card already retrieved once is always typed, and a picked answer is at most Good. Listen: "Show the text" waits for a second listen and that sentence does not count as understood by ear. Watch: the meaning needs the Slovak shown first. |
| Input before output | A new unit's first lesson opens with two "What does it mean?" reps: the whole sentence spoken, the target form marked, three meanings to pick from. The choose and type reps follow; once a unit is practiced the lesson is production almost throughout. |
| Sources (`/sources`) | The research behind every task, by feature (E63): what the studies found, what they did not show, which numbers are the app's own choice, and a link to each paper (97 sources, 91 with a DOI link that was checked against Crossref, 4 whose abstracts were read against the claim; the rest are cited from the research notes and say so). Every task folds the same text into a "Why this works" note on its own screen. `npm run sources:check` re-checks the DOIs; the text lives in `src/core/sources.ts`. |
| When can I…? (`/milestones`) | The calculator (October 2026: "when will I understand most of a Slovak YouTube video?"). Six situations — a casual vlog, the news, a café or shop, the in-laws, a film with and without subtitles — plus any you add in your own words (mapped once by the cheap model slot to a kind of language, a coverage target, a speaker rate and the support the situation gives; kept in `data/profiles/<language>/milestones.json`). For each, two gaps measured separately: **words** (your working vocabulary — the deck and word lessons, plus the commonest words your level implies — against the lemmas the kind of language needs for 95% or 98% of its running words, from Nation 2006, Webb & Rodgers 2009, Adolphs & Schmitt 2003, raised a quarter for Slovak's morphology) and **speed** (words a minute of understanding from the Listen task's per-sentence timing and, when it exists, the Watch task, against the speaker's rate discounted for pictures, subtitles or the right to ask again). Dates at your planned minutes and at your real two-week pace; the later gap decides. Speed grows along the guided-hours ladder anchored to the CEFR listening descriptors until eight of your own Listen sessions replace it with your trend. Evidence panel, a timeline, the next words that pay most (one tap into Review), every study cited. Opened from Today's goal line and from the hours sheet. |
| This week's balance | Under the daily plan: the week's minutes by Nation's four strands (input, speaking, words & rules, speed) against a quarter each, with the strand furthest behind named. The minutes are measured while you were active; Talk, Story and tutor sessions have no timer, and days before minutes were measured never had one, so those count each activity's planned minutes, and the card says how many. A tight daily budget keeps one task per strand (Listen, Speak, Read, Speed) before a second drill. The research note behind all three is the "Comprehensible Input and LangHarness" page. |

Start or Enter opens it; under it, "Find a video at your level" (when no video waits) and "One more lesson". A goal can be up to 600 minutes while the plan holds about 35 to 45, so this is where a long day goes, and deliberate study stays about a quarter of the week. |
| Listening outside the app | November 2026, on Today: **Log listening** records a podcast, TV or a video in another player: minutes (up to 600 an entry), **Focused** or **In the background**, the day (today or the two before), and what it was; each entry can be removed. It is kept in `data/profiles/<language>/outside-listening.json` and never counts toward your minutes, XP, streak, stamps or the week's balance, because the app cannot measure it. The Milestones page says how much you logged and adds a "Speed with outside listening" row to each situation: your measured pace plus focused outside minutes at half, background at none. Those weights are the app's own assumption (no study gives one); on your own Listen trend the row says the outside listening is already in it. The research is in `docs/research/outside-listening.md`. |
| Stamps (`/progress#stamps`) | *Turistické známky*, the round wooden stamps hikers collect at every Slovak peak and hut, as the app's record of outcomes (November 2026, E31, `docs/research/gamification.md`): a summit stamp per level, a stamp per chapter, and 42 deeds (your first lesson; 7, 30, 100 and 365 days in a row; 50 to 3,000 words known; 100 to 5,000 review answers; lessons without a miss; words once missed, now known; a week with all four kinds of practice; stories read; scenes said aloud; listening sessions; Blitz scores; hours on the trail; chapter exams passed). A stamp is earned by an outcome on record, never by an action; it carries no XP, buys nothing, and once earned keeps its day. A lesson that earns one presses it onto the end screen. Today's Stamps card shows the last one earned and the three closest with their counts; the book on Progress shows them all in three groups. The This week card counts the days practiced against the days a week in your goal and says when the target is met. Progress also keeps a trail log: hours on the trail, words known, days practiced, longest streak, lessons, review answers, stories read, scenes said aloud. No leaderboards, hearts or currency, by rule. |
| Cheatsheets (`/words?tab=cheatsheets`) | Phrase lists you keep at hand for a game, a trip or a call (November 2026, E50). Edited as a table by default: a section name, then a row per phrase with Phrase, Say it, Meaning and Note, and Add phrase / Add section buttons; Enter moves to the next phrase and adds one after the last, Ctrl+Enter saves, and closing with changes asks first. A **Text** view takes a pasted list, one line per phrase: `phrase | say it | meaning | note`; a line with no `|` starts a section. **New cheatsheet** creates one from a title and its phrases. An open sheet has **Add phrases** (paste lines; only the phrases it lacks are added, to the section they name, else a new section at the end) and **Edit** (the title and the whole text). The sheet has a **Jump to a section** menu, a play button per phrase, and **Cover the <language>**, which hides every phrase until you have said it and pressed it. **Add N words to Review** puts the sheet's dictionary words into the deck, 30 at a time; Review drills them in the dictionary's own sentences, never in the sheet's lines (E27). A sheet belongs to the running language. One you make in the app stays on this computer, in `data/profiles/<language>/cheatsheets/<id>.json`; every version an edit or an add replaced, and a removed sheet, moves to `trash/`. **Move to repo** turns it into `curriculum/<language>/cheatsheets/<title>.txt`, a text file with `# Title` on its first line that you commit like the rest of the curriculum; every such file shows in the list as "in the repo", and Edit and Add phrases write it in place (git keeps its history; the app never deletes one). The Russian Animal Hospital sheet is `curriculum/russian/cheatsheets/animal-hospital.txt`. The packaged desktop app does not carry these files; run from the repo to use them. |
| Ear gym (`/phonology`) | Train your ear on pairs of words that differ in one sound (November 2026, E86, E87, E88). A round is ten pairs: you hear one word and pick it from two large tiles, with the letters that differ underlined (keys 1 and 2, Space plays it again, "I can't tell" counts as a miss); then both words play from their tiles so you can compare them, with one line on how the two sounds differ. The band at the top shows the ten pairs, filled for one heard right and hollow for a miss. The end screen gives the score for each contrast, weakest first (tap one to train it), and lists the pairs you missed. The pairs are those of the language you are learning: Slovak (vowel length, soft consonants, syllabic r, diphthongs, voicing) and Russian (hard and soft consonants, и and ы, ш and щ); another language gets a plain "No pairs yet" screen. For Slovak a second view, Rhythm, shows the rule that two long syllables never stand side by side: type a word to see each syllable as long or short. A round is practice only: no XP, nothing saved. |

## Run it

```
npm install
npm run dev          # http://localhost:3010
```

Add a model key in Settings → API keys as in LearnHarness.

Optional speech keys (Settings → API keys → Speech, or `.env.local`):

- `ELEVENLABS_API_KEY`: the best voice, and speech-to-text for the Speak task (Scribe). Change the voice with `ELEVENLABS_VOICE_ID_SK` or `ELEVENLABS_VOICE_ID`. Every language is read with `eleven_v4` (set `ELEVENLABS_MODEL_ID` for another); an account without it falls back to `eleven_v3`, then `eleven_multilingual_v2` for the 29 languages that one reads. Single words and the tutor's lines in a language without its own ElevenLabs voice use Edge unless `ELEVENLABS_VOICE_ID_<CODE>` (for example `ELEVENLABS_VOICE_ID_ET`) names one. `npm run audio:regen` lists the kept clips the newest model would make better (an older model, or an Edge clip in a voice ElevenLabs has) with their characters and cost, and spends nothing; `npm run audio:regen -- --yes` makes them again (`--max-chars` caps the spend). Replaced files move to `data/audio/replaced/<stamp>/`.
- `DEEPGRAM_API_KEY`: speech-to-text for the Speak task when there is no ElevenLabs key (and the composer's dictation).
- `AZURE_SPEECH_KEY` + `AZURE_SPEECH_REGION`: Azure Speech pronunciation assessment (Slovak is covered) for Speak and Speed — a phoneme-level score for every spoken line. Without them clarity is judged from the transcript alone.
- `LH_PRON_SCRIPT=1`: dev only — a made-up pronunciation score for working on the screens without a key. `LH_STT_SCRIPT=<text>`: dev only — every recording transcribes to that text.
- `LH_SPEAK_SCRIPT=<file>`: dev only — a JSON array of scripted tutor replies for working on the Speak screen without a model.
- Edge voices need no key, only internet.
- Piper works offline: set `PIPER_PATH` to the binary and `PIPER_MODEL_SK` to a Slovak `.onnx` voice.

On Windows, `npm test` and `npm run desktop:dev` use Unix-style env syntax
inherited from upstream. Run them from Git Bash, or once run
`npm config set script-shell "C:\Program Files\Git\bin\bash.exe"`.

## Refresh the curriculum

```
npm run lexicon:export   # reads ../slovak.wiki, writes curriculum/slovak/lexicon.json
npm run seed:build       # curriculum/slovak/seed-source.json → seed.json
```

The seed source is hand-written. Edit nodes, chains, clusters or goals
there, then rebuild. An existing profile is not re-seeded. To start
fresh, delete `data/profiles/slovak/`.

## Limits worth knowing

- Only 4 words (from slovak.wiki's hand-checked set) have full declension tables checked against JÚĽŠ. 2,958 more have rule-generated form sets that slovak.wiki verified. For the rest, `lookup_word` says plainly that the form is not in the dictionary.
- Slovak is the only built-in language. Russian, Estonian and the others are added from **Add a language…** (see above).
- Estonian and Russian come with a course written by hand (`curriculum/estonian/`, `curriculum/russian/`): every case and verb form is drilled where Tatoeba has the sentences, and the rest is covered by tutor sessions. Another added language gets a course generated when it is added. The Dvojičky pairs and the aspect tasks are Slovak content and do not appear for the others.
- Edge speech could not be tested in the build sandbox (no network there). The fallback to the next tier was tested.
- Example sentences come from slovak.wiki's curated set or from Tatoeba (CC BY 2.0 FR). The review page credits them, and each card names which one it is.
