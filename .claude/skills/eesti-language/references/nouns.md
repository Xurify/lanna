# Noun Morphology & Declension (Nimisõna ja käänamine)

Estonian noun inflection operates on 14 cases across singular and plural. There is no grammatical gender.

## 1. The Three Base Forms (Põhivormid)

Every noun has three indispensable base forms from which the rest of the paradigm is formed:

| Form | Estonian | Example 1 (*auto*) | Example 2 (*leib*) | Example 3 (*linn*) | Function |
| --- | --- | --- | --- | --- | --- |
| Base 1 | Nimetav (Nom. Sg.) | *auto* | *leib* | *linn* | Subject, dictionary form |
| Base 2 | Omastav (Gen. Sg.) | *auto* | *leiva* | *linna* | Singular cases 4–14, Nom. Pl., Gen. Pl. stem |
| Base 3 | Osastav (Part. Sg.) | *autot* | *leiba* | *linna* | Direct object, counting with 2+, Part. Pl. base |

---

## 2. Derivation of the Singular Cases

All singular oblique cases (cases 4 through 14) are formed by appending the case ending directly to the **Genitive singular** stem:

```
Genitive Singular: toa (from tuba "room")
├─ Illative:    toa + sse  = toasse (or short illative: tuppa)
├─ Inessive:    toa + s    = toas
├─ Elative:     toa + st   = toast
├─ Allative:    toa + le   = toale
├─ Adessive:    toa + l    = toal
├─ Ablative:    toa + lt   = toalt
├─ Translative: toa + ks   = toaks
├─ Terminative: toa + ni   = toani
├─ Essive:      toa + na   = toana
├─ Abessive:    toa + ta   = toata
└─ Comitative:  toa + ga   = toaga
```

---

## 3. The Short Illative (Lühike sisseütlev)

In addition to the regular *-sse* ending, many common nouns have a synthetic short illative. In speech and natural writing, the short illative is preferred whenever available.

| Formation Type | Rule | Nominative | Genitive | Short Illative | Regular Illative |
| --- | --- | --- | --- | --- | --- |
| **Vowel lengthening / Q3** | Final vowel remains, syllable is pronounced in overlong (Q3) length | *kool* | *kooli* | *kooli* (Q3) | *koolisse* |
| **Consonant strengthening** | Strong grade with geminate consonant | *tuba* | *toa* | *tuppa* | *toasse* |
| **Stem vowel / synthetic form** | Monosyllabic diphthong/long vowel stem | *maa* | *maa* | *maha* / *maasse* | *maasse* |
| **-he ending** | Historical *h*-stems take *-he* | *pähe* (*pea*) | *pea* | *pähe* | *peasse* |
| **Stem change** | Irregular historical roots | *vesi* | *vee* | *vette* | *veesse* |
| | | *käsi* | *käe* | *kätte* | *käesse* |
| | | *kodu* | *kodu* | *koju* | *kodusse* |
| | | *jõgi* | *jõe* | *jõkke* | *jõesse* |
| | | *linn* | *linna* | *linna* (Q3) | *linnasse* |

## 4. Plural Formation Mechanics

### Nominative Plural
Always: **Genitive singular stem + *-d***.
- *tuba* (Gen: *toa*) -> *toad*
- *leib* (Gen: *leiva*) -> *leivad*
- *linn* (Gen: *linna*) -> *linnad*
- *inimene* (Gen: *inimese*) -> *inimesed*

### Genitive Plural
Formed by adding *-de* or *-te*:
1. **-de**: Words ending in a vowel in Gen. Sg. with weak or vocalic stems (*majade, autode, kalade, tubade*).
2. **-te**: Words with consonant partitive stems or strong consonant codas:
   - *mets* (Part: *metsa*) -> *metsade* or *metste*
   - *mees* (Part: *meest*) -> *meeste*
   - *laps* (Part: *last*) -> *laste*
   - *tütar* (Part: *tütart*) -> *tütarde*
   - *keel* (Part: *keelt*) -> *keelte*

### Partitive Plural (Mitmuse osastav)
The most morphologically diverse case. Four main patterns:
1. **-sid**: Default for foreign words, words ending in *-e*, or diphthong stems:
   - *auto -> autosid*, *idee -> ideesid*, *ratsu -> ratsusid*.
2. **-id**: Very common after a vocalic genitive stem:
   - *raamat -> raamatuid*, *laul -> laule / laulusid*, *pank -> panku / pankasid*.
3. **Vowel change (-e, -i, -u)**: Synthetic plural partitive:
   - *a -> e*: *kala -> kalu / kalasid*, *tuba -> tube*, *vana -> vanu*.
   - *e -> i*: *leib -> leibu*, *keel -> keeli*.
   - *u / o -> i*: *lind -> linde*, *kool -> koole*.

### Plural Cases 4–14
Regularly formed from the **Genitive Plural stem** + case ending:
- Gen. Pl: *majade* -> *majades, majadest, majadele, majadel, majadelt, majadeks, majadeni, majadena, majadeta, majadega*.
- Gen. Pl: *meeste* -> *meestes, meestest, meestele, meestel, meestelt, meesteks, meesteni, meestena, meesteta, meestega*.

## 5. Locative Usages for Settlements & Proper Names

Estonian place names diverge on whether they take internal (*-sse, -s, -st*) or external (*-le, -l, -lt*) cases.

| Settlement / Country | In / At (*Kus?*) | To (*Kuhu?*) | From (*Kust?*) | Rule / Notes |
| --- | --- | --- | --- | --- |
| **Tallinn** | *Tallinnas* | *Tallinnasse / Tallinna* | *Tallinnast* | Internal (most cities) |
| **Tartu** | *Tartus* | *Tartusse / Tartu* | *Tartust* | Internal |
| **Pärnu** | *Pärnus* | *Pärnusse / Pärnu* | *Pärnust* | Internal |
| **Narva** | *Narvas* | *Narvasse / Narva* | *Narvast* | Internal |
| **Viljandi** | *Viljandis* | *Viljandisse / Viljandi* | *Viljandist* | Internal |
| **Haapsalu** | *Haapsalus* | *Haapsallu* | *Haapsalust* | Internal (*-llu* short illative) |
| **Võru** | *Võrus* | *Võrru* | *Võrust* | Internal (*-rru* short illative) |
| **Saaremaa** | *Saaremaal* | *Saaremaale* | *Saaremaalt* | External (all *-maa* names) |
| **Hiiumaa** | *Hiiumaal* | *Hiiumaale* | *Hiiumaalt* | External |
| **Eesti** | *Eestis* | *Eestisse* | *Eestist* | Internal |
| **Soome** | *Soomes* | *Soomesse* | *Soomest* | Internal |
| **Venemaa** | *Venemaal* | *Venemaale* | *Venemaalt* | External (*-maa*) |
| **Ameerika** | *Ameerikas* | *Ameerikasse* | *Ameerikast* | Internal |

### Compound Nouns (Liitsõnad)
In compound nouns, only the final component inflects:
- *sünnipäevakink* (birthday gift):
  - Genitive: *sünnipäevakingi*
  - Partitive: *sünnipäevakinki*
  - Allative: *sünnipäevakingile*
