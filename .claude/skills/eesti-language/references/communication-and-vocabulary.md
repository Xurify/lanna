# Practical Communication and Thematic Vocabulary (Suhtlus ja sõnavara)

Token-minimized reference for high-frequency communicative frames and essential vocabulary across CEFR A1–B1 (drawn from the Keeleklikk and Keeletee curricula).

---

## 1. Greetings, Introductions, and Social Formulas

| Situation | Estonian Phrase | English Translation | Grammar / Usage Note |
| --- | --- | --- | --- |
| **Greeting** | _Tere!_ | Hello! | Universal neutral greeting |
|  | _Tere hommikust!_ | Good morning! | Elative _-st_ formula |
|  | _Tere päevast!_ | Good day / afternoon! | Elative _-st_ formula |
|  | _Tere õhtust!_ | Good evening! | Elative _-st_ formula |
|  | _Tsau! / Tšau!_ | Hi! / Bye! | Informal |
| **Inquiring** | _Kuidas läheb?_ | How is it going? | Neutral inquiry |
|  | _Kuidas käsi käib?_ | How are things? | Idiomatic |
|  | _Hästi, aitäh!_ | Well, thanks! | Standard reply |
|  | _Pole viga._ | Not bad / So-so. | _pole_ + Partitive |
| **Name** | _Mis su / teie nimi on?_ | What is your name? | Informal _su_, formal _teie_ |
|  | _Minu nimi on..._ | My name is... | Genitive _minu_ + _nimi_ |
| **Origin** | _Kust sa pärit oled?_ | Where are you from? | Elative _kust_ |
|  | _Olen pärit Eestist / Ameerikast._ | I am from Estonia / America. | Elative _-st_ |
| **Residence** | _Kus sa elad?_ | Where do you live? | Inessive _kus_ |
|  | _Ma elan Tallinnas / Tartus._ | I live in Tallinn / Tartu. | Inessive _-s_ |

## 6. Work and Professions (Töö ja ametid)

To state one's profession, Estonian uses the **Essive case (_-na_)**:

- _Kellena sa töötad?_ (What do you work as?)
  - _Töötan tarkvaraarendajana._ (I work as a software developer.)
  - _Ta töötab koolis õpetajana._ (She works as a teacher in a school.)
  - _Minu vend töötab arstina._ (My brother works as a doctor.)

## 7. Celebrations, Calendar, and Wishes (Tähtpäevad ja soovid)

Wishes and festive greetings use the **Translative case (_-ks_)**:

- _Palju õnne sünnipäevaks!_ (Happy birthday! — literally "Much happiness for birthday")
- _Head uut aastat!_ (Happy New Year! — Partitive)
- _Häid jõule!_ (Merry Christmas! — Partitive plural)
- _Head isu!_ (Bon appétit! — Partitive)
- _Head teed! / Head reisi!_ (Have a safe trip! — Partitive)
- _Õnnitleme teid pulmapäeva puhul!_ (Congratulations on your wedding day!)
