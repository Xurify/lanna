# Russian Communication, Etiquette, and Vocabulary

Social interaction in Russian requires navigating register, naming formulas, polite distance, and avoiding critical false friends.

## 1. The T–V Distinction: _Ты_ vs. _Вы_

Russian distinguishes informal singular _ты_ from formal/plural _вы_:

| Address                    | Target & Context                                                                          | Etiquette Rules                                                                                                         |
| -------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Вы** (Formal singular)   | Adult strangers, service personnel, teachers, doctors, business associates, acquaintances | The default polite address. In formal correspondence addressed to one specific individual, capitalized as **Вы / Ваш**. |
| **Вы** (Plural)            | Any group of two or more people (regardless of familiarity)                               | Always takes plural verb and adjective agreement (_Вы готовы?_).                                                        |
| **Ты** (Informal singular) | Family members, close friends, peers/classmates among youth, children under ~14           | Never address an adult stranger as _ты_. Transitioning from _вы_ to _ты_ (_перейти на «ты»_) requires mutual agreement. |

## 2. Eastern Slavic Naming Conventions

A full Russian name consists of three elements: **Имя (Given Name) + Отчество (Patronymic) + Фамилия (Surname)**.

| Component                     | Example                                       | Formation & Meaning                                                                  | Context of Use                                                                               |
| ----------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| **First Name + Patronymic**   | _Александр Сергеевич, Анна Ивановна_          | Patronymic formed from father's name: `-ович / -евич` (masc), `-овна / -евна` (fem). | The highest standard of respectful address in business, education, government, and medicine. |
| **Hypocoristic / Short Name** | _Саша (Александр), Маша (Мария), Ваня (Иван)_ | Formed with `-а/-я`.                                                                 | Used between friends, family, peers with _ты_.                                               |
| **Diminutive / Endearing**    | _Сашенька, Машенька, Ванюша, котик_           | Formed with diminutive suffixes `-еньк-, -ушк-, -ик-`.                               | Intimate affection, parents to children.                                                     |
| **Surname Alone**             | _Иванов, Смирнова_                            | Typically `-ов/-ова, -ин/-ина, -ский/-ская`.                                         | Official rosters, police, roll calls.                                                        |

## 3. High-Value Situational Formulas

| Function                 | Formal / Standard                                       | Informal / Friendly            |
| ------------------------ | ------------------------------------------------------- | ------------------------------ |
| **Greeting**             | _Здравствуйте! Добрый день! Доброе утро! Добрый вечер!_ | _Привет! Здорово!_             |
| **Farewell**             | _До свидания! Всего доброго! Всего хорошего!_           | _Пока! До скорого! До завтра!_ |
| **Thanks**               | _Большое спасибо. Благодарю вас._                       | _Спасибо! Спасибочки!_         |
| **Responding to thanks** | _Пожалуйста. Не за что. На здоровье._                   | _Не за что! Да ладно!_         |
| **Apology**              | _Извините. Прошу прощения. Извините за беспокойство._   | _Прости. Извини._              |
| **Agreeing / Accepting** | _Конечно. Согласен / Согласна. С удовольствием._        | _Давай! Договорились! Ладно!_  |
| **Refusing politely**    | _К сожалению, не могу. Боюсь, что не получится._        | _Не, не выйдет._               |
| **Asking to repeat**     | _Повторите, пожалуйста. Я не расслышал(а)._             | _Что? Как ты сказал?_          |

## 4. Crucial False Friends (_Ложные друзья переводчика_)

Cross-linguistic interference causes severe errors if assumptions from English or other Slavic languages are applied blindly:

| Russian Word   | True Meaning in Russian                 | What Learners Mistake It For (Trap)       | True Russian for the Mistaken Word |
| -------------- | --------------------------------------- | ----------------------------------------- | ---------------------------------- |
| **чёрствый**   | stale (bread), unfeeling                | fresh (Slovak _čerstvý_)                  | _свежий_                           |
| **овощи**      | vegetables                              | fruit (Slovak _ovocie_)                   | _фрукты_                           |
| **позор**      | shame, disgrace                         | attention (Slovak _pozor_)                | _внимание_                         |
| **неделя**     | week                                    | Sunday (Slovak _nedeľa_)                  | _воскресенье_                      |
| **красный**    | red                                     | beautiful (Slovak _krásny_, archaic Rus.) | _красивый_                         |
| **родина**     | homeland / motherland                   | family (Slovak _rodina_)                  | _семья_                            |
| **живот**      | belly / stomach                         | life (Slovak _život_)                     | _жизнь_                            |
| **магазин**    | shop / store                            | periodical magazine                       | _журнал_                           |
| **город**      | city / town                             | castle (Slovak _hrad_)                    | _за́мок / крепость_                 |
| **заказать**   | to order (food, goods)                  | to forbid (Slovak _zakázať_)              | _запретить_                        |
| **аккуратный** | neat, tidy, punctilious                 | accurate (English accurate)               | _точный, правильный_               |
| **фамилия**    | surname / last name                     | family (English family)                   | _семья_                            |
| **артист**     | performer / actor                       | painter / fine artist                     | _художник_                         |
| **кабинет**    | private office / study / treatment room | kitchen cupboard / cabinet                | _шкаф / шкафчик_                   |
