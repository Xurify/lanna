# Russian Practice, Assessment, and Progression

Curriculum authoring and pedagogical progression must align with the official State Standards for Russian as a Foreign Language (ТРКИ / TORFL).

## 1. The TORFL / ТРКИ Level Framework

| ТРКИ Level             | CEFR Equiv. | Active Lexicon | Grammatical Benchmark Scope                                                                                                                                                                                                            |
| ---------------------- | ----------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Элементарный (ТЭУ)** | **A1**      | ~780 words     | All 6 cases in basic singular meanings; basic plural nominative/accusative; present, past, future; imperative; motion verbs _идти/ходить, ехать/ездить_; _по-, при-_; short adjectives _рад, должен, занят, болен_; _у меня есть/нет_. |
| **Базовый (ТБУ)**      | **A2**      | ~1300 words    | Plurals across all cases; comparatives and superlatives; motion verbs with _в-, вы-, у-, под-, от-, до-, пере-_; _лететь, нести, везти_; conditional with _если бы_; indirect question with _ли_; telephone discourse.                 |
| **Первый (ТРКИ-1)**    | **B1**      | ~2300 words    | All 4 participles (active/passive, present/past); short passive participles; verbal adverbs (_деепричастия_); passive with `-ся`; complex clauses of concession, cause, result; abstract vocabulary.                                   |
| **Второй (ТРКИ-2)**    | **B2**      | 5000+ words    | Full stylistic range; official documents (_заявление, доверенность, резюме_); all 7 intonational constructions (ИК); nuanced modal and expressive idioms; high conversational fluency.                                                 |

## 2. Diagnostic Error Taxonomy

When analyzing student errors in drills, categorize by root linguistic mechanism:

| Code              | Error Category             | Manifestation                                                                          | Remediation Strategy                                                                                         |
| ----------------- | -------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **ERR-CASE-GOV**  | Preposition / Verb Valency | Using wrong case after preposition or verb (_помогать + acc_ instead of _dat_).        | Isolate the governing head word; show the minimal pair with required case question (_кому?_).                |
| **ERR-ANIM**      | Animacy Failure            | Using nominative instead of genitive for masculine animate object (_я видел студент_). | Check animacy hierarchy: person/animal + accusative = genitive ending.                                       |
| **ERR-PAUCAL**    | Numeral Agreement          | Using nominative plural after 2, 3, 4 (_два столы_ instead of _два стола_).            | Reinforce the historical dual rule: 2, 3, 4 take Genitive Singular in nominative contexts.                   |
| **ERR-ASPECT**    | Aspect Confusion           | Using imperfective for completed single event or perfective in present tense.          | Contrast process vs result; test with time markers (_долго, часто_ vs _вдруг, за час_).                      |
| **ERR-MOTION**    | Motion Verb Misdirection   | Using _идти_ for habitual trips or for vehicle travel.                                 | Contrast foot (_идти/ходить_) vs vehicle (_ехать/ездить_); single trip (_идти_) vs round trip (_ходить_).    |
| **ERR-SPELL-7**   | 7-Letter Rule Breach       | Writing _ы_ after _г, к, х, ж, ч, ш, щ_ (_книгы_).                                     | Enforce standard orthographic filter: write _и_, never _ы_.                                                  |
| **ERR-VOWEL-RED** | Vowel Reduction Error      | Spelling words phonetically based on sound (_спаси́бо_ written _спаси́ба_).              | Highlight base dictionary stem and stress position (_аканье_ in pronunciation, etymological _о_ in writing). |

## 3. Curriculum and Drill Authoring Rules

When writing drills, cloze items, or assessment cards for Russian:

1. **Unambiguous Context:** A fill-in-the-blank item must contain sufficient syntactic cues (preposition, governing verb, or subject agreement) so that exactly one form is grammatically correct.
   - Poor: _Я вижу ___ (сестра)._ (Both _сестру_ and _сестёр_ could be valid without context).
   - Good: _Я вижу мою младшую ___ (сестра)._ (Governs _сестру_ uniquely).
2. **Prepositions Inside the Blank:** If a preposition has mobile forms (_в/во, с/со, к/ко, о/об/обо_), include the preposition inside the cloze token if the target word dictates the variant:
   - Example: _Он подошёл ___ (к + я) на улице._ → Target: _ко мне_.
3. **Cyrillic Script Only:** Never present Russian exercises in Latin transliteration. Transliteration masks palatalization and orthographic rules.
4. **Mark Stress Pedagogically:** In prompts and explanations for A1–B1 learners, always place combining acute stress marks (U+0301) on words of two or more syllables, and preserve `ё`.
5. **Authentic Tatoeba Sentences:** Ensure example frames reflect genuine native collocations rather than calqued English syntax.
