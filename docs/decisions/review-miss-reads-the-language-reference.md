# A miss on another word reads the language reference: the passage that sets the two words side by side, or the aspect pair (2026-11-11, branch `fix/review-miss-contrast`)

The owner, on the 62.3% of [review-miss-explains-from-the-apps-own-data](review-miss-explains-from-the-apps-own-data.md)'s common pairs left with only an example sentence: "Can you and another agent go through finding an implementation into how we can get to coverage for almost everything and test it out, whether you decide it's with AI, or not, or a compromise". Two tracks ran side by side: this one (no model) and [review-miss-ai-note-once-per-pair](review-miss-ai-note-once-per-pair.md) (a model, checked).

**Why:** the Slovak reference chapters the tutor already reads (`.claude/skills/slovak-language/references`, the `slovak_reference` tool) set many of the uncovered pairs side by side in their own words: v/na and do/na in the spatial table, pre/za in the cause table, žiť/bývať, stať sa/diať sa, hovoriť/povedať/rozprávať and the leave verbs in the lexical-choice table, and 84 aspect pairs in the aspect chapter. Review never read them.

**How to apply:**
- **What counts as a passage** (`referenceUnits`, `referenceContrast`, `src/core/reference-contrast.ts`): a table, a code block of "frame  gloss" lines, or one prose line, each cut at semicolons. The card shows only the clauses that name one of the two words, one per line, and the chapter's title ("From the reference: Valency and Prepositions.").
- **What counts as naming a word:** the word on its own, with sa or si, heading a frame with "+", or in an explicit "X vs. Y" row. Never a word inside an example sentence or a longer phrase (len in "len čo").
- **What is skipped:** a big table (over ten rows) or a word-list table pairs only within one row; a clause listing more than eight words; a row headed by a third word; two spellings written as alternants (s/so); chapters about spelling, sound, practice, paradigms and authoring (`notAboutMeaning`, `src/agent/language-reference.ts`).
- **Case names in full:** the reference's "loc.", "acc.", "+ L" read "locative", "accusative" on the card ([E23-full-grammar-words-and-one-spelling](E23-full-grammar-words-and-one-spelling.md)).
- **Aspect pairs** (`referenceAspectPairs`): tables whose columns are labeled perfective and imperfective, each cell one verb with its sa or si. The card says which is which and adds the curated aspect rule from `mixups.json`.
- **Order on the card:** curated rule, aspect pair, reference passage, then [review-miss-ai-note-once-per-pair](review-miss-ai-note-once-per-pair.md)'s note, then [review-miss-explains-from-the-apps-own-data](review-miss-explains-from-the-apps-own-data.md)'s parts of speech, gloss note, question, example.
- **Checked:** every aspect and reference line the card would show for a common pair was read: 35 of 36 right, and the wrong one (s/so) is now skipped. Each skip rule has a test (`tests/reference-contrast.test.ts`).
- **Per language:** only Slovak has a reference that the desktop build ships, so only Slovak reads one.
